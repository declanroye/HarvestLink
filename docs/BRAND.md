# HarvestLink identity

The custom linked-fields H connects two upright stems with a shared crossing and a gold diagonal route. It expresses separate producers becoming one coordinated supply network. The mark uses original vector geometry drawn for this project.

![HarvestLink identity](harvestlink-brand.svg)

Forest **#174D40** anchors actions and trust; mineral **#F5F7F3** creates a quiet workspace; muted gold **#B6A067** marks the connecting route. A restrained system sans-serif wordmark and headings keep the tool legible on low-cost devices without downloading fonts. Use the same mark for the workspace, companion icon and future business sender profile.

The shared Twilio Sandbox identity is controlled by the provider. Updating these assets does not change that sender's WhatsApp name or logo; an approved HarvestLink business sender is a separate launch step.
